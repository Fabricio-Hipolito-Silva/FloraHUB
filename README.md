# 🌿 FloraHUB

> Hub pessoal para gerenciamento e integração de dispositivos IoT.

## 📖 Sobre o projeto

O FloraHUB é um projeto pessoal desenvolvido para centralizar
e controlar dispositivos físicos através de uma interface web.

O projeto tem como objetivo servir como uma plataforma própria
para integração entre dispositivos IoT, servidores e aplicações web.

Atualmente, o primeiro dispositivo sendo integrado ao FloraHUB é o
Lighter, uma lâmpada inteligente controlada através da
Tuya Developer Platform.
